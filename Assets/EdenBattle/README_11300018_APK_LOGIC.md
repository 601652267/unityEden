# 11300018 APK 战斗演出说明

## 播放入口

人物战斗场景只保留 `APK 原逻辑版`，普通攻击、爆气和奥义按钮会直接按 XAPK 1.0.19 中的角色资源映射、Lua 时序和 Timeline 播放。界面不再提供版本切换按钮，`Tab` 也不再切换播放逻辑。

## APK 资源组合

| 动作 | 角色动作 | 使用的原始资源 |
|---|---|---|
| 普通攻击 | `attack` | `eft_fx_11300018_attack_2.aab` |
| 爆气 | `skill` | `eft_fx_11300018_attack.aab`、`eft_fx_11300018_skill.aab`、`eft_fx_11300018_skill_2.aab` |
| 奥义 | `uniqueskill` | `eft_fx_timeline_11300018_xp.aab`、`FX_timeline_11300018_xp.m4v` |

`attack_air` 和 `attack_air_hit` 属于空中攻击分支，资源仍在项目中并纳入验证，但当前三个地面动作按钮不会调用它们。

普通攻击和爆气的粒子预制体会保留原包内的发射延迟与绝对坐标：

- `attack_2`、`skill_2` 的根节点已写入原防守方坐标 `(18.5, -4, 0)`，因此从世界原点实例化。
- `attack`、`skill` 是目标相对资源，由播放器对齐到当前敌人。

`eft_labi_shouji.aab` 仍作为原始资源保留并参与完整性检查，但不在普通攻击中生成。该包的 `labi_shouji/mesh_labi_gj_plane` 是蓝色三角扇形网格，参考视频中的普通攻击没有这一画面。

普通攻击和爆气的敌方受击点来自预制体演出与参考画面的对应关系，不表示伤害计算或服务器判定。
