# 11301006 原版录像逐帧结论

分析基准：用户提供的 `普通攻击.mov`、`爆气.mov`、`奥义.mov`，三段均为 60 FPS。
录像包含点击后的等待时间，下面的技能时间以 Spine/特效开始帧重新归零，因此不是播放器总时间。

## 普通攻击

- 施法者从开始到结束保持原战斗站位，没有向目标突进。
- `FX_11301006_attack` 应在施法者位置生成，表现为法杖亮起并向右发射。
- 不能整体放大 `FX_11301006_attack`。其中完整的法杖光效是 `FX_11301006_attack_grp/glow (17)` 及其子节点，必须让这一组的根节点跟随法杖；只移动使用 `FX_daoguang_004_sh` 的单个子粒子不会改变画面中主体光效的位置。普通攻击开始约 0.1 秒时，法杖 Region 的第 1 组边缘顶点是杖头，第 2 组在法杖下端，因此整组光效跟随第 1 组端点。
- `_attack_2` 位于受击方。
- 三次伤害约在技能开始后 0.33、0.46、0.59 秒出现，对应 `3000:3000:4000`。
- 约 0.85 秒恢复待机并清理展示特效。

## 爆气

- 施法者全程保持原战斗站位，没有移动。
- 技能开始约 0.35 秒后，球体在施法者头顶形成，持续蓄力至约 1.35 秒。
- 随后球体飞向受击方；目标侧爆炸约在 1.45 秒后开始。
- `FX_11301006_skill_2` 的三组收尾命中粒子延迟为 3.00、3.30、3.40 秒，对应 `3000:3000:4000`；受击动作按这三个实际粒子时刻同步。
- `FX_11301006_skill` 必须以施法者为锚点；`FX_11301006_skill_2` 保留原始目标绝对 X，并补偿目标 Y。
- `FX_11301006_skill` 不能整体放大，否则头顶法阵和蓄力球会过大。只让 1.70–1.90 秒出现的六个武器发光节点跟随 Spine 法杖头，并保留它们彼此之间的原始相对间距；`skill_2` 完全不改。
- 最后一组粒子在 3.40 秒出现、余辉约 0.35 秒，因此约 4.10 秒恢复待机并清理展示特效；早于 3.75 秒清理会直接截掉最后一击。

## 奥义

奥义录像与 `skillscript11301006.lua.bytes` 的显隐、视频和 16 段伤害顺序一致。Timeline 整体仍使用原始 `y=-4`；在 4.5 秒发射瞬间，运行时分别计算 `FX_zidan01`、`Shoot-baofa` 与 Spine 法杖头的实际世界 Y 差，只给这两个节点增加一次校正父节点。这样光球起点与杖头同高，同时保留后续原始飞行轨迹，也不会移动整条 Timeline 的其他特效。
